# عودة التتار - تطبيق الموبايل

## الخطوات

### 1. رفع المشروع لـ Replit
- انسخ مجلد `mobile-app/` كمشروع جديد في Replit
- اختر template: React Native / Expo

### 2. تثبيت Dependencies
```bash
npm install
```

### 3. إضافة الأيقونات
- استبدل `assets/icon.png` بأيقونة اللعبة (1024x1024)
- استبدل `assets/splash.png` بشاشة التحميل (1284x2778)

### 4. تعديل الرابط (إذا تغير)
- افتح `App.js` وعدل `GAME_URL`

### 5. النشر
- من Replit اختر Deploy → App Store / Google Play
